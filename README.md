# QuickSpecCheck
QuickSpecCheck ensures you never pull a boss in the wrong gear or talents again!

Whenever you zone into a Dungeon, Raid, or Delve, QuickSpecCheck instantly plays a high-priority Raid Warning sound and freezes an unmissable modal popup in the center of your screen. To clear the alert, you must actively click OK, giving you a quick moment to verify your setup before the key or encounter starts.

Talent Loadout Detection: Displays your active Specialization alongside your specific saved Talent Build name (e.g., Retribution - Raid Single Templar).

Equipment Set Tracking: Shows your currently equipped Equipment Manager set name (or alerts you if you're wearing un-saved/custom gear).

Unmissable Alerts: Combines audio alarms and a modal dialog window that requires user dismissal—no subtle chat messages you'll scroll past.

Lightweight & Plug-and-Play: Zero configuration needed. Just install and go—it automatically activates only when passing through instance loading screens.
